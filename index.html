Resumo Geral

Em 2025, a HDL avançou na modernização de seus processos e iniciou o desenvolvimento de um projeto estratégico: o Sistema HDL Gestão. A plataforma, atualmente em 35% de desenvolvimento, visa criar um BI financeiro para substituir planilhas manuais e elevar o padrão de apresentação de resultados aos clientes.

Em paralelo, o Vector (PDV) evoluiu para uma versão mais robusta e empresarial, e o Tareffa recebeu novos processos no setor de Legalização. Projetos de infraestrutura como Agendamento e Telefonia IP permanecem estáveis e em pleno uso.

Os desafios atuais se concentram na gestão de dependências externas: aguardamos uma atualização crítica do Tareffa Comunicação (prevista para 12/12) para prosseguir com a migração do DigiSac, e a evolução do sistema Quark (RH) depende do input de dados pela equipe interna da HDL.

Novo Projeto em Andamento: Sistema HDL Gestão

Objetivo do Projeto

Desenvolver uma plataforma web multiempresa para gestão e apresentação de resultados financeiros (Faturamento x Impostos x Lucro), substituindo planilhas por um dashboard automatizado e profissional para reuniões com clientes.

Status Atual das Entregas (35%)

  • Infraestrutura e Backend (Em Andamento): A estrutura inicial do banco de dados MySQL (tabelas de Empresas, Usuários) foi definida. A API REST em Node.js foi iniciada, com as rotas de autenticação e segurança básicas já implementadas.
  • Frontend e Interface (Iniciado): O projeto frontend foi estruturado com React e Tailwind CSS. A prototipação do layout do dashboard, menu e seletor de empresas está em andamento.
  • Funcionalidades de Negócio (Planejado): As próximas etapas incluem o desenvolvimento das regras de negócio (cálculos de impostos, lucro), a criação dos relatórios analíticos com exportação para PDF e o módulo inteligente de lançamentos.

Tecnologias

Stack: React.js, Vite, Tailwind CSS (Frontend) | Node.js, Express, MySQL (Backend).

Tareffa — Status e Próximas Entregas

Legalização: Foram implementados novos processos para otimizar o fluxo de trabalho. Adicionalmente, está em estudo uma nova estrutura de Kanban para melhorar a visualização e gestão das tarefas do departamento.
Demais Setores (Financeiro, Contábil, Fiscal, DP): Mantêm os processos atuais, com foco na consolidação do uso e na identificação de pequenas melhorias. As pendências de adoção na Contabilidade e a criação do processo Fiscal continuam como pontos de atenção.

Vector / PDV — Evolução e Novos Objetivos

O PDV foi atualizado para uma versão empresarial, incorporando um conjunto significativo de novas funcionalidades que o tornam mais competitivo e robusto. O sistema continua acessível em pdv.wavegt.com.br e está em ciclo de melhoria contínua.

Como próximo passo estratégico, está em análise um método para que as vendas registradas no PDV sejam automaticamente lançadas como faturamento direto nos sistemas de gestão, otimizando a conciliação financeira para os clientes.

Quark — Gestão de RH

O módulo de Departamento Pessoal foi introduzido no sistema. A próxima fase do projeto, que inclui a configuração de rubricas financeiras e a inserção de modelos de documentos, foi delegada a Aline (RH), que ficou responsável por alimentar o sistema com as informações necessárias para a sua plena operação.

DigiSac e Tareffa Comunicação

O DigiSac permanece como a ferramenta oficial de atendimento, operando de forma estável. O plano de migração para o Tareffa Comunicação está pausado, aguardando uma atualização do fornecedor prometida para o dia 12 de dezembro. Após essa data, a viabilidade da integração será reavaliada.

Telefonia IP — Manutenção

A infraestrutura de Telefonia IP está estável e em uso contínuo por toda a equipe. A manutenção e o suporte técnico da solução são de responsabilidade da Sanfer.

Observações & Próximos passos

  • Avançar no desenvolvimento do Sistema HDL Gestão, com foco na finalização da API e construção do dashboard interativo.
  • Definir e implementar a nova estrutura de Kanban para o setor de Legalização no Tareffa.
  • Analisar e desenvolver a funcionalidade de registro de faturamento direto no Vector/PDV.
  • Reavaliar a integração do Tareffa Comunicação após a atualização de 12/12 para decidir sobre a migração do DigiSac.
  • Acompanhar com Aline (RH) o progresso da inserção de dados no sistema Quark.
  • Agendar e realizar novo treinamento com a equipe de Contabilidade sobre o uso do Kanban no Tareffa.
