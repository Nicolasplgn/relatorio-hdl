HDL Gestão Financeira

Fase: Pré-Produção

1. Visão Geral Executiva

O projeto evoluiu de protótipo para um SaaS de Inteligência Financeira funcional. A aplicação permite gerenciamento completo de múltiplas empresas (Multi-tenant lógico), focando na automação de cálculos tributários e projeções. Arquitetura ajustada para acesso em rede local (Mobile/Desktop) agnóstico ao IP.

2. Status dos Módulos (Frontend)

  • 📊 Dashboard Executivo (Concluído) Design System "Premium/Clean" com Tailwind e animações Framer Motion. Gráficos híbridos (Receita x Lucro), Drill-down tabular e exportação PDF em alta resolução (html2canvas).
  • 💰 Gestão de Lançamentos (Concluído) UX otimizada com separação visual de Receitas/Custos/Impostos (ICMS, PIS, COFINS). Cálculo de Margem e totais em tempo real (Live Preview).
  • 🏢 Gestão de Empresas & BI Integração API para preenchimento via CNPJ. Suporte a Simples Nacional, Lucro Presumido/Real. Simulador de Cenários e alertas fiscais de teto de faturamento.

3. Infraestrutura & Backend

  • ⚙️ Backend (API REST Node.js) Pool de conexões MySQL resiliente (mysql2/promise). Servidor escutando em 0.0.0.0 para acesso via rede local (Wi-Fi/LAN).
  • 🛡️ Segurança & Conectividade Uso de Axios com Agente HTTPS para ignorar erros de SSL em redes corporativas. Fallback automático na consulta de CNPJ (BrasilAPI -> ReceitaWS).
  • 🔧 Desafios Técnicos Superados
    • Correção do erro ERR_CONNECTION_REFUSED com detecção dinâmica de IP.
    • Solução para Falha CNPJ (Erro 500) com tratamento robusto.
    • Fim do carregamento infinito no BI com lógica real de agregação.
